# Direction

## Current horizon

Land and keep legible the first owner-bounded Goal Space/operator projection:
source-owned adapters, explicit freshness/missingness, non-executing
annotations and action intents, and a public repository identity. The organ
must remain useful as a read surface without becoming a second role, routing,
runtime, proof, memory, stats, or acceptance plane.

## Next bounded pressure

The next contour is not automatic admission. It is a named access request for
one concrete owner surface with an explicit capability, currentness policy,
effect ceiling, proof packet, and rollback. The natural owner must be named
before implementation begins. If no such contour exists, keep the registry
record absent and continue using derived observations.

## Stop-lines

- Do not create `aoa-goals`.
- Do not let dashboard config create owner authority or canonical bindings.
- Do not wake, branch, approve, execute, or select a winner from the UI.
- Do not treat absent producer coverage as zero.
- Do not call local tests, GitHub landing, or registry presence live admission.
- Do not widen the organ before the existing owner surface is shown absent and
  the new contract is accepted by its natural owner.
